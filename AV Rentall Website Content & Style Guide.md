# AV Rentall Website Content & Style Guide

## 1. Brand summary

**AV Rentall** is positioned as a full-service entertainment technology and event infrastructure supplier. The visual language from the PDF is deliberately monochrome, premium, technical, and spacious: a near-black hero treatment, off-white editorial content sections, bold black headlines, thin dividers, restrained cool-gray/steel-blue accents, and precise grid alignment.

The website should feel capable of supporting both a boardroom briefing and a 10,000-capacity open-air concert. It should communicate production confidence rather than generic equipment rental.

## 2. Recommended color system

The values below are derived from the rendered PDF and should be treated as a practical web palette rather than a formal color standard.

| Token | Hex | Usage |
|---|---:|---|
| Ink / Near Black | `#161616` | Hero backgrounds, dark process section, footer, primary text on light backgrounds |
| Paper / Off White | `#F7F7F7` | Main page background and light sections |
| Pure White | `#FFFFFF` | Logo on dark backgrounds, high-contrast text, cards on dark sections |
| Mist Gray | `#EAEBEE` | Secondary panels, chart surfaces, subtle separators |
| Cool Steel | `#D3DBE3` | Pills, soft backgrounds, inactive bars, light UI accents |
| Slate Blue | `#516A80` | Icons, links, chart lines, focus states, small accent details |
| Deep Slate | `#273746` | Chart bars, dark cards, strong secondary accent |

Use black and off-white for roughly 90% of the interface. Use Slate Blue sparingly for affordances, icons, links, diagrams, and data accents. Avoid gradients, neon colors, glossy glassmorphism, and overly decorative shadows.

## 3. Typography direction

The PDF uses a geometric sans-serif style with bold, compact headings and clean regular body text. Use **Plus Jakarta Sans**, **Manrope**, or **Inter** as a web-safe approximation. Recommended hierarchy:

| Role | Recommendation |
|---|---|
| Display heading | Extra-bold or bold sans-serif; tight line-height around `0.95–1.05` |
| Section label | Uppercase, small size, medium weight, increased tracking, pill or soft-gray background |
| Body copy | Regular sans-serif, comfortable line-height around `1.45–1.65` |
| CTA | Medium/bold sans-serif, compact, clear contrast |
| Numbers / metrics | Bold sans-serif with generous spacing and strong alignment |

Use sentence case for major headings, uppercase only for navigation labels, section tags, and compact metadata.

## 4. Suggested website information architecture

Build a single long-form homepage with anchored sections and optional supporting pages for Services, Equipment, and Contact. The homepage order should be:

1. Hero / brand promise
2. Company overview
3. Services
4. Market position / capability proof
5. What sets AV Rentall apart
6. Event types
7. Equipment rental
8. Process
9. Contact / enquiry CTA

The navigation should remain compact and high contrast. Suggested navigation labels are `Services`, `Capabilities`, `Equipment`, `Process`, and `Contact`. The primary navigation CTA should read `Start a Conversation`.

## 6. Layout and interaction guidance

Use a responsive 12-column grid on desktop and a single-column flow on mobile. Keep the hero dark and cinematic, with the light logo, a concise heading, the exact hero statement, and two CTAs: `Explore Services` and `Start a Conversation`. Use a low-opacity technical grid or fine horizontal rules as background texture rather than decorative illustrations.

Use service cards with minimal borders, small line icons, and short paragraphs. The process section should use a dark background and a horizontal five-step flow on desktop, collapsing to a vertical numbered timeline on mobile. Contact details should be immediately actionable: `tel:`, `mailto:`, and a WhatsApp deep link for the phone number.

Use the supplied PDF charts only as visual reference unless the underlying figures are confirmed. Do not imply that the percentages or market-growth values are audited research data. The 30% / 55% / 15% audience mix can be rendered as a clear visual only if it is intended as company positioning data.

## 8. Accessibility and content requirements

Maintain WCAG-conscious contrast between the near-black/white pair and the slate-blue accent. Provide descriptive alt text for every photography asset. Do not use the charts as the only way to communicate percentages or process steps; include the text labels in the DOM. Make phone, email, website, and WhatsApp details keyboard accessible. Preserve the exact company name as `AV Rentall` in body copy and `AV RENTALL` only when reproducing the logo wordmark.
